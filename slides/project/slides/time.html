EIOPA’s file has no years, only 45-year totals, and its four versions move mainly with re-pricing and corrections. So we used the EEA annual data on the same CATDAT records. Because one event can dominate a year, we read 10-year windows. They stay between 75 and 84% uninsured since 1990. A fitted trend gives minus 2.2 points per decade with a Newey-West standard error of 1.5, so not significant. Meanwhile average annual losses tripled, so the uninsured amount grows. By hazard, flood improved from 90 to 79%, storms worsened. The 1980s peak is the Irpinia earthquake in Italy.
