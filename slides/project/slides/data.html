2 · The data

Two datasets built on the same loss records

EIOPA dashboard, 2025 version

30 EEA countries × 5 perils. Cumulative 1980–2024 totals in € million, CPI-adjusted. CATDAT main, EM-DAT check, plus a sheet on each insurance system.

EEA annual series, 2026 release

Same CATDAT records, by country and year, 2024 prices. Adds heatwaves and droughts, lacks the supervisors’ corrections. Used for the trend.

Perils missing

No drought peril. Hail is not separate: it is counted inside windstorm (convective storms).

Caveats we found

Each release re-prices and revises the past. Sources disagree: Croatian earthquakes €1.3bn (CATDAT, kept) vs €13.8bn (EM-DAT).

EIOPA’s file gives 45-year totals, not years, so for the time question we added the EEA’s country-year series, which uses the same CATDAT records. If asked about Croatia: we keep CATDAT’s €1.3bn for consistency; with EM-DAT’s €13.8bn Croatia’s burden rises from 1.0 to 4.3 per mille of GDP a year, second after Slovenia. Hail is in windstorm; drought is missing from EIOPA but present in the EEA series.
